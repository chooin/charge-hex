上电：Boot 交接到应用

Boot 读取 PB0 和 0x0800F802 升级标记，选择升级等待或尝试进入 App。App 复制 45 项向量到 SRAM，初始化 GPIO、DMA、TIM、双串口、I²C、IWDG 与 ADC，再进入裸机主循环。

升级：先暂存，再提交 Flash

USART1 接收升级控制与文件 → I²C 设备暂存 → 按 1 KiB 页写入 App Flash → 更新 metadata → 结果上报 / 握手后尝试启动 App。当前 Boot 仍为旧实现；本项目没有已验收的升级包。

RAM 更新不等于引脚已经变化

0x0800C85C / charge_channel_set_state() 更新通道位图及双位状态。常规循环在 0x0800B0A6 调用 0x08007474，发送高、低两字节并锁存；部分专用业务路径也会主动调用刷新。

接收侧与业务侧分工

DMA / IRQ 维护接收缓冲及标志，主循环再消费。USART1 走完整块校验，USART2 走逐字节解析；其 mode 1 完成后不进行业务分派。新 C RX API 尚未接入原缓冲，图中解析仍为旧路径。
